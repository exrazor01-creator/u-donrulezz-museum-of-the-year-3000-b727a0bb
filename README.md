## Why it fits the brief

1. **On subject:** a museum label a museum in the year 3000 puts beside an ordinary object from today.
2. **Joke lands on first read:** the laugh is in the line itself — "a test most humans failed".
3. **Year-3000 misreading:** the curators call it "a ritual test" for proving visitors were human — nearly true, and absurd.
4. **Reads like a real label:** object, date, deadpan description; short, straight-faced, confident, no throat clearing.
5. **Fresh object and angle:** a CAPTCHA, not the brief's own examples (fork, parking meter, house key, group chat).
